## 🚀 Featured Projects

### 🛡️ TokenGuard — Intelligent LLM Cost Optimizer

A production-inspired middleware that protects LLM applications from excessive API costs by automatically compressing oversized prompts before sending them to cloud models. It uses a locally hosted LLM for prompt optimization, supports response caching, and integrates seamlessly through a Python decorator.

**Tech:** Python • Local LLMs • Prompt Engineering • Caching • API Optimization

---

### 📚 Adaptive RAG — Multi-Strategy Document Intelligence

An advanced Retrieval-Augmented Generation (RAG) system that enables users to upload documents and ask natural language questions. The application dynamically selects the most effective retrieval strategy—**Vector**, **Knowledge Graph**, or **Tree-based Retrieval**—or allows manual selection. It supports multimodal document understanding by extracting insights from both text and images while returning context-aware answers with relevant visual references.

**Tech:** Python • LangChain • RAG • Vector Databases • Knowledge Graphs • Multimodal AI
